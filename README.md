# ℹ️ Information
Likkut is an experimental vibe coded Minecraft: Java Edition server software project focused on learning, experimentation, and building a server implementation from the ground up.

> [!NOTE]
> Likkut is not afilliated with Mojang or Microsoft.

## 🚧 Current status
Likkut is currently in **early development**.

### Currently Implemented
- [x] Java/Maven project
- [x] Server startup and shutdown lifecycle
- [x] `server.properties` configuration
- [x] Console command handling
- [ ] Colored console logging
- [x] Linux support/testing
